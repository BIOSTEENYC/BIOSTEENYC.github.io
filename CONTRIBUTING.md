# Contributing

Thanks for your interest in contributing! Small contributions like typos, new poems or translations are welcome.

How to contribute:

1. Fork the repository.
2. Create a feature branch: `git checkout -b fix/my-change`.
3. Make your changes (edit `index.html` for site content, poems in `rawPoetryDatabase`).
4. Run locally and test.
5. Open a Pull Request describing your change.

Guidelines:
- Keep changes focused and small.
- Use UTF-8 encoding for text.
- Add translations to the `translations` object when adding new UI text.

If you need help, open an issue or contact the maintainer (Telegram: Biosteenyc).
