## Lokalda ishga tushirish
Statik sayt bo‘lgani uchun quyidagicha ochish yetarli:

```bash
git clone https://github.com/biosteenyc/BIOSTEENYC.github.io.git
cd BIOSTEENYC.github.io
python3 -m http.server 8000
# keyin: http://localhost:8000
```

Yoki:

```bash
npx http-server -c-1
```

## Qanday o‘zgartirish mumkin
- She'rlar: `index.html` ichidagi `rawPoetryDatabase` massiviga yangi obyekt qo‘shing.
- Tarjimalar: `translations` obyeki orqali yangilang.
- CV/PDF URL'lari: `index.html` ichidagi `CV Yuklash` yoki `openPDFViewer` funksiyalaridagi linklarni tahrir qiling.
- Dizayn/animatsiyalarni alohida CSS/JS fayllarga ajratish tavsiya etiladi agar loyiha o‘sishni davom ettirsa.
